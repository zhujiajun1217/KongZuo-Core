## 关键结构检查

1. **不能将幕后地下返场道与东侧工作门混同。** 本版只做 B1 楼梯封闭外观，不开放 B1；东门位于后台通廊东端，朝外窄巷。
2. **禁止对结局下定论。** “取钥匙的女人＝沈芸”在剧照后可确认；“沈芸乘车、顾兰藏票、许承山纵火/切电、谁锁门、死亡和地下逃路”在当前试玩 UI 中不能当作已证实事实。
3. **时代不混。** 2004年调查视角不能把1992残响解读为玩家亲临/改变过去；钥匙有“1992周明生遗物钥匙”与“2004维修钥匙”两把不同道具。
4. **目标时长**：V0.3设计是序章6:30、第一章12:00、第二章18:00，合计36:30。当前灰盒只验证交互链，不据此声称达标。
5. **门槛恢复**：旧照对景＋点交单关联才触发第一章残响；末尾必须检视并记录门内侧的锁座/划痕才显示“未完待续”。

## 建议给小组的 QA 用例

- [ ] 第一次从前厅进入观众厅（未完成电话与登记表），不应触发人影。
- [ ] 完成电话、座位、登记表，再从前厅重入观众厅，才触发人影一次。
- [ ] 不完成第一章照片对景，尝试点击七号座不会直接播取钥匙残响。
- [ ] 完成对景与点交单但未按 Tab 关联，仍提示去笔记确认。
- [ ] 关联后七号座出现取钥匙残响、女子说“我知道”，之后进入第二章。
- [ ] 进入后台：拿2004维修钥匙才能打开普通工作区门；档案室/配电室/B1仍封闭。
- [ ] 检视剧照可确认身份，生活照补充顾兰关系；购票凭证不会被记为“已上车”。
- [ ] 许承山的争执残响保留抓腕动作与“你不能现在走”，纸条再给出共同出走的其他解释。
- [ ] 不看顾兰可选纸套，也可完成整段剧情。
- [ ] 未具备身份、生活照、购票凭证、许承山纸条、钥匙登记，无法推进东门尾声。
- [ ] 到东门触发残响后，必须再拍门锁与划痕才能到“那一晚，门没有为她打开／未完待续”。
- [ ] 全部流程没有提示“谁锁门”“谁弄倒油灯”“谁藏票”“沈芸死于何处”。
- [ ] 全过程红色 Console 错误为零；首次体验记录入场、第一残响、化妆间、购票凭证、东门结尾的时间点。
