# 主线 P0 验收用例

| 测试项 | 操作 | 期望 |
|---|---|---|
| QA01 首次启动 | 00_Bootstrap→Play | 先展示清点表，E收起后可以移动 |
| QA02 门禁 | 未收起清点表时试门 | 不能绕过工作单直接进楼 |
| QA03 线索顺序A | 电话→椅背→登记表→重返 | 仅一次人影 |
| QA04 线索顺序B | 登记表→椅背→电话→重返 | 与A一样 |
| QA05 缺线索 | 仅两项调查→重返观众厅 | 不触发人影 |
| QA06 恢复触发 | 人影出现后退出厅，再回来靠近 | 能完成灯闪，不重播人影起始事件 |
| QA07 纸张 | 人影消失后看椅子/纸张 | 能读节目单，关闭后过章 |
| QA08 笔记 | Tab打开 | 只显示已经获得的线索 |
| QA09 谜题缺证据 | 未看票根时摆对并提交 | 不能成功 |
| QA10 谜题未填 | 留一个可填写座位空白 | 提示尚未填写 |
| QA11 七号锁定 | 按数字2 | 七号始终为空 |
| QA12 人物卡唯一 | 反复切换6/8号 | 同一观众不会同时占用两座 |
| QA13 谜题错误 | 6号乙、8号甲，Enter | 明确错误且可再次调整 |
| QA14 谜题正确 | 6号甲、7号空、8号乙，Enter | 仅开始一次残响 |
| QA15 演出回退 | 完整看完残响 | 回2004，群演和钥匙消失，恢复行走 |
| QA16 碰撞 | 门厅→办公室→售票口→观众厅→侧阶 | 没有陷地、卡住、穿墙 |
| QA17 多人协作 | 队友克隆main后打开 | 同版本且所有`.meta`正确 |
| QA18 构建 | Build Profiles Windows PC | Bootstrap→序章→第一章完整可用 |

这些用例需要在目标 Unity 编辑器中实际 Play 验收；静态检查不能替代编辑器编译、试玩或 Windows 构建。
