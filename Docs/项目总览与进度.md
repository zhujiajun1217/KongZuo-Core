# 项目总览

## 当前主线

本仓库维护可运行的桌面主线，不混放独立演示和旧版本。

| 顺序 | 场景 | 用途 |
|---|---|---|
| 1 | `Assets/KongZuo/Scenes/00_Bootstrap.unity` | 游戏入口 |
| 2 | `Assets/KongZuo/Scenes/01_Prologue.unity` | 序章 |
| 3 | `Assets/KongZuo/Scenes/02_Chapter01.unity` | 第一章 |

Build Profiles 也只配置上述三个场景。序章和第一章使用的戏楼 Prefab 为
`Assets/KongZuo/Art/KZ_OperaHouse_P0_V03/Generated/Prefabs/KZ_OperaHouse_P0_V03_From11_Final.prefab`。
模型来源、编辑器整合菜单和已知验证边界见[戏楼模型接入说明](模型接入说明.md)。

## 开发环境

- Unity `6000.3.26f1`，Universal Render Pipeline，Windows PC。
- 克隆后运行 `git lfs install` 和 `git lfs pull`，再用 Unity Hub 打开仓库根目录。
- 场景、Prefab 和其他 Unity 资源的 `.meta` 文件必须与资源一起保留。

## 验证状态

- Unity 导入与脚本编译通过。
- 项目没有 EditMode 自动化测试。
- 完整 Play 流程、碰撞检查和 Windows 构建仍待人工验收，见[主线 QA](QA_主线.md)。
- 不将导入成功、静态检查或单场景预览描述为完整游戏验收。

## 协作

在独立功能分支开发并通过 PR 合并。涉及 `01_Prologue.unity` 或
`02_Chapter01.unity` 时先协调唯一场景负责人；提交 Unity 资源时一并提交对应
`.meta`。PR 应说明影响范围、实际验证步骤、结果和未完成项。
