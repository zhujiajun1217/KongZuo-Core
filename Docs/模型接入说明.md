# 戏楼模型接入

## 主线资源

- 美术源场景：`Assets/KongZuo/Art/KZ_OperaHouse_P0_V03/Generated/Scenes/KZ_LatestModel_From11.unity`
- 主线 Prefab：`Assets/KongZuo/Art/KZ_OperaHouse_P0_V03/Generated/Prefabs/KZ_OperaHouse_P0_V03_From11_Final.prefab`
- 使用 Prefab 的场景：`01_Prologue.unity`、`02_Chapter01.unity`

源场景含预览对象，不能直接作为游戏入口。主线场景使用最终 Prefab。
序章和第一章使用同一戏楼 Prefab，并同步五处模型高度校正。重新运行整合菜单时会为两个场景统一应用并检查这些校正；不会改写场景中的剧情或谜题逻辑。

## 编辑器工具

打开 Unity `6000.3.26f1`，等待导入结束后，在菜单运行：

- `Tools > 空座 > 整合 > 检查序章与第一章`
- 需要重新接入模型时，再运行 `Tools > 空座 > 整合 > 将戏楼美术接入序章和第一章`

脚本会检查玩家、HUD、剧情导演、相机、模型层级及缺失脚本。整合工具可从美术源场景重新生成主线 Prefab；请保留源场景及其 `.meta` 文件。

结构检查不代替实际 Play、碰撞和 Windows 构建验收。
